# OBS AR Engine

Open Source Augmented Reality Engine for OBS Studio.

## Vision

OBS AR Engine est un moteur de réalité augmentée dédié à la diffusion sportive.

Le premier objectif est le basket-ball, avec projection d'éléments 2D et 3D directement sur le terrain.

Le moteur sera compatible :

- macOS
- Windows

Le cœur du moteur sera indépendant d'OBS afin de pouvoir être réutilisé dans d'autres applications.
